## The entry

> Introducing the Apologetic Door: it says 'sorry, my bad' every time you stub your toe on it, because the stubbing was never going to stop — but the blame can finally be shared.

## Files

- `entry.txt` — the entry itself, byte for byte what the program writes out.
- `main.py` — copies `entry.txt` into the output directory the harness sets (`$MAKEFUN_OUTPUT_DIR`, or `/output` when unset).
